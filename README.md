# 🐾 PetNova Portugal

Loja de demonstração de acessórios para cães e gatos em Portugal.

## Estado
- Site estático no GitHub Pages, com carrinho de simulação.
- Não existem pagamentos nem encomendas reais.
- Produtos e preços são exemplos, sem fornecedores confirmados.

## Conteúdos automatizados gratuitos
O ficheiro `produtos.csv` guarda o catálogo inicial.
Executa `python automacao_conteudos.py` num computador com Python 3 para gerar cinco rascunhos na pasta `conteudos/`. Não precisa de API paga.

**Limites:** este gerador utiliza modelos de texto, não uma IA generativa externa. Não gera vídeos nem publica nas redes sociais. Estas funções precisam de ferramentas, permissões e testes adicionais.

## Antes de vender
Verificar fornecedores, prazos de entrega, segurança dos produtos, faturação, privacidade, devoluções, informação ao consumidor e pagamentos adequados à atividade em Portugal.
